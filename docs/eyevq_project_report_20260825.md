# EyeVQ 模型架构与实验总结

> 配置只依据验证集选择。测试集在历史开发中已被观察，因此测试结果仅作为内部探索结果。

> 2026-08-25 默认配置更新：正式数据路径已切换为 V6，并使用从 V6
> 重新计算的分眼 area statistics 与 manual features。后文的 V3/V4/V5
> 数值仍是历史消融记录，不代表当前默认数据路径。

## 1. 数据与处理流程

### 1.1 数据组成

每名受试者完成朝向眼跳、反向眼跳、记忆眼跳和双眼跳四类任务。每次任务执行形成一条试次，疾病标签属于受试者，而不是单条试次。

| 数据流 | 通道 | 含义 |
|---|---|---|
| 刺激 | fixation on、stimulus on、x、y | 固定点状态、目标状态和目标位置 |
| 左眼 | x、y、area、blink | 视线位置、瞳孔面积和眨眼 |
| 右眼 | x、y、area、blink | 与左眼相同，参数共享但数据独立 |
| 有效性 | nonmissing/quality | 区分真实测量、缺失帧和 padding |
| 人口学 | 16维 | 年龄、年龄缺失、性别和教育编码 |

连续序列先切成不重叠 patch，再按时间组织为刺激、左眼、右眼三类 token。双眼同时无效的试次在 Tokenizer、BERT 和下游阶段全部删除；BERT 只遮挡双眼都满足有效阈值且不是 padding 的位置。

| Patch 参数 | 设置 |
|---|---:|
| 每个 patch 的采样点 | 40 |
| Stride | 40 |
| 每条试次最大 patch 数 | 128 |
| BERT 可遮挡阈值 | L/R nonmissing 均不低于 0.85 |

### 1.2 数据版本

最新流水线曾采用 V5 数据，但复核数据来源后确认：交付输入本身已经完成滤波，V5 构建阶段不应再次改变坐标信号。现有 V5 生成器却对输入额外执行了保护式 75 Hz Butterworth 零相位低通，因此当前 V5 是重复滤波产物，不是正确的数据版本。基于该产物得到的结果仅保留为内部探索记录，不作为论文主结果或最终模型依据。

- V3 有条件地过滤高频变化。
- V3.1 主要标记缺失，基本保留全部高频变化。
- V4 是上一版信号处理结果。
- 正确 V5 应直接使用交付数据中已经滤波的坐标，仅生成 QC/缺失标签、manual feature、packed 数据和索引，并沿用既有 trial 身份、顺序、subject key 与 train/validation/test 划分；不得再次滤波。

因此，当前磁盘上的 V5 与 V4 虽保持相同划分，但其坐标差异包含一次不应发生的额外滤波，不能据此归因数据策略收益。正确 V5 必须从已经滤波的交付输入重新生成，构建阶段保持坐标逐帧不变，并通过哈希或逐值审计验证没有二次滤波。

V6 并没有修正这一问题。代码审计对 V5/V6 的 224 个 packed 数组文件逐一比较后未发现任何差异；V6 只是重新打包 V5 payload，因而完整继承 V5 的保护式 75 Hz 处理。V6 构建脚本中的“no filtering”只能解释为“V6 阶段没有再追加滤波”，不能解释为原始或未滤波信号。

### 1.3 归一化

坐标使用固定几何尺度。瞳孔面积按受试者、按左右眼分别计算中位数和 MAD：

$$
\tilde a_{s,e,t}=\operatorname{clip}\left(
\frac{a_{s,e,t}-\operatorname{median}(a_{s,e})}
{1.4826\max(\operatorname{MAD}(a_{s,e}),32)},-5,5\right).
$$

分眼归一化用于消除眼别基线、设备尺度和有效帧比例差异。面积不再额外使用 `log1p`，避免重复压缩低幅度变化。人口学统计只在训练折拟合，再应用于验证和测试。

## 2. 模型架构

### 2.1 总体流程

```text
刺激 + 左眼 + 右眼连续轨迹
          │
          ▼
Tokenizer：重建连续信号并产生离散 FSQ code
          │
          ▼  一次性缓存 code ID，随后冻结 Tokenizer
BERT：同步遮挡左右眼 patch，预测离散 code
          │
          ▼  每条试次的 CLS 表征
下游分类：试次平均 → 任务平均 → 受试者预测
```

BERT 训练期间不调用 Tokenizer。Code-ID cache 与 Tokenizer checkpoint、数据版本、FSQ 配置和左右眼排列校验值绑定，失配时必须重算。

### 2.2 Tokenizer

刺激和眼动使用独立 patch embedding，左右眼共享 eye embedding。类型嵌入区分刺激、左眼、右眼和 CLS；位置嵌入表示时间；质量嵌入表示有效比例。

Tokenizer 使用结构化联合 self-attention：

- 刺激 query 只读取有效刺激 token。
- 左眼、右眼和 CLS query 可以读取有效刺激与眼动 token。
- Stimulus 不读取 CLS 或眼动，因此信息方向符合“刺激驱动眼动”。
- 该结构是带 attention mask 的 self-attention，不是额外 cross-attention。

| Tokenizer 组件 | 设置 |
|---|---:|
| Encoder | 12层，384维，8 heads，FFN 1152 |
| Decoder | 3层，384维 |
| Dropout | 0 |
| FSQ | `[9,7,5,5]` |
| 联合 code 数 | 1,575 |
| 量化函数 | 标准 tanh FSQ |

左右眼状态固定按 `[L0,R0,L1,R1,...]` 排列，再投影为四个 FSQ 维度。Decoder 仅接收量化后的眼动表示，重建 XY、Area 和 Blink，并预测试次级连续与二值描述符。

$$
\mathcal L_{tok}=\mathcal L_{xy}+0.1\mathcal L_{area}
+0.1\mathcal L_{blink}
+0.0015(0.25\mathcal L_{feat}^{bin}+1.5\mathcal L_{feat}^{cont}).
$$

| 损失项 | 类型 | 权重/处理 |
|---|---|---:|
| XY | Smooth L1 | 1.0 |
| Area | Smooth L1 | 0.1 |
| Blink | BCE | 0.1，positive weight 1.0 |
| Velocity | Smooth L1 | 0，不参与总损失 |
| 连续手工特征 | Smooth L1 | group 0.0015，内部 1.5 |
| 二值手工特征 | BCE | group 0.0015，内部 0.25 |
| Count 特征 | — | 不参与损失 |

Velocity 是 XY 的一阶差分。单独提高其权重会重复强化坐标目标，并在早期放大高频梯度，因此正式配置将其关闭。

### 2.3 BERT 预训练

BERT 直接读取原始 patch，使用独立于 Tokenizer 的 embedding。Stimulus 始终可见；一个时间位置被选中时，左眼和右眼同时遮挡，避免模型从另一只眼复制同步轨迹。

| BERT 组件 | 设置 |
|---|---:|
| Encoder | 12层，384维，8 heads，FFN 1152 |
| Dropout | 0 |
| Mask | L/R 同位置同步遮挡 |
| 统一参考 span | 长度1–5等概率 |
| Mask ratio | 0.60，按有效 patch 计算 |
| Prediction head | 9、7、5、5四个分类头 |
| Label smoothing | 0 |

FSQ 四维分别计算交叉熵。模型先在每条试次内部平均有效遮挡位置，再对所有有效试次平均，避免长试次获得更大权重。

$$
\mathcal L_i=\frac{1}{|M_i|}\sum_{t\in M_i}\sum_{d=1}^{4}
\operatorname{CE}(h_d(z_{i,t}),q^d_{i,t}),\qquad
\mathcal L_{BERT}=\frac{1}{|I|}\sum_{i\in I}\mathcal L_i.
$$

分维度预测比联合 1575 类预测提供更稠密的监督：部分维度预测正确时仍能产生有效学习信号。

### 2.4 受试者级 K16 分类

K 表示每名受试者、每个任务在一次训练中抽取的不同试次数。K4 每任务抽4条；K16 每任务抽16条。旧实现将16条分成四组再平均，在共享分类头、一致性损失为零且使用算术平均时，与直接平均16条严格等价，因此统一称为 K16。

每条试次产生一个384维 CLS。模型先对 CLS 做 LayerNorm，再拼接16维人口学向量，通过共享分类头得到原始分类分数。随后先平均同任务试次，再等权平均四类任务。每名受试者只计算一次分类损失。

| 下游组件 | 设置 |
|---|---:|
| 输入 | LayerNorm(CLS 384) + demographics 16 |
| 分类头 | `400→128→C`，GELU，dropout 0.3 |
| 试次聚合 | K16 logits mean |
| 任务聚合 | 四任务等权 mean |
| 解冻范围 | 冻结 embedding 和底部4层，训练顶部8层 |
| MCI | 正类加权，阈值固定0.5 |
| PD5 | 类别逆频率加权，argmax |

验证和测试使用所有有效试次，不进行随机 K16 抽样。

## 3. 训练配置

| 阶段 | Batch | 训练量 | 学习率 | Warmup | Matrix WD |
|---|---:|---:|---:|---:|---:|
| Tokenizer | 128/GPU × 4 | 40K steps | `3e-4→3e-5` cosine | 2K | 0.01 |
| BERT | 128/GPU × 4 | 50K steps | `3e-4→3e-5` cosine | 2K | 0.05 |
| MCI | 4 subjects/GPU × 4 | 最多50 epochs | `1e-5→1e-6` cosine | 4 epochs | 0.05 |
| PD5 | 4 subjects/GPU × 4 | 最多100 epochs | `1e-5→1e-6` cosine | 4 epochs | 0.05 |

所有阶段使用 bf16、AdamW、梯度裁剪；bias、归一化参数和所有一维参数不使用 weight decay。下游按原始 validation AUROC 早停，结束后加载 validation-best checkpoint 再测试。

### 4.1 最新 Tokenizer 与 BERT

| Tokenizer 40K | Val L_feat | 0.15677 |

Tokenizer 码本接近全量使用，没有坍缩。Area 是主要剩余重建项。最新取消 stimulus-to-CLS 注意力的 BERT 已完成预训练，但下游三种子仍未完成，因此尚不能替代已验证参考。

### 4.2 BERT mask 候选

下表均为三个随机种子的受试者级结果。

| BERT 策略 | MCI Val | MCI Test | PD5 Val | PD5 Test |

|---|---:|---:|---:|---:|
| K4 | 0.8852 | 0.8784 | 0.0136 | 0.8824 |

## 5. 消融总结

### 5.1 数据版本

| 数据 | MCI Val/Test | PD5 Val/Test | 结论 |
|---|---:|---:|---|
| V3 | 0.8801 / 0.8667 | 0.8812 / 0.8747 | 高频 target 较复杂 |
| V3.1 | 0.8731 / 0.8889 | 0.8645 / 0.8785 | 全量高频无稳定收益 |
| **V4** | **0.8931 / 0.9018** | 0.8718 / **0.8837** | 双任务最均衡 |

### 5.2 FSQ 容量

| FSQ | Codes | MCI Val/Test | PD5 Val/Test | 结论 |
|---|---:|---:|---:|---|
| **[9,7,5,5]** | 1,575 | 0.8790 / 0.9004 | **0.8854** / 0.8733 | 稳定默认 |
| [9,7,7,5,5] | 11,025 | **0.9107** / 0.8875 | 0.8671 / 0.8799 | 更稀疏，跨任务收益不一致 |

当前码空间已足够表达数据，继续扩大 FSQ 会显著增加 BERT 目标稀疏性。

### 5.3 其他消融结论

| 因素 | 最佳选择 | 主要证据 |
|---|---|---|
| Mask 形态 | 双眼同步连续 span | 避免跨眼复制；随机低比例 mask 对 MCI 过于简单 |
| Mask 时间尺度 | 统一模型用1–5 | 更长 span 提升 MCI，但降低 PD5 |
| BERT 训练量 | 50K | 80K 降低预训练 CE，但无统一下游收益 |
| Trial 数 | K16 | 提高均值并降低种子方差 |
| Task 完整性 | Strict four-task | Partial-task 恢复样本但下游下降 |
| 聚合 | Shared logits mean | CLS 拼接、残差融合和可学习 task weight 更易过拟合 |
| Demographics | 原始16维直接拼接 | 升维增加过拟合，过度降维丢失信息 |
| Head | Hidden 128，dropout 0.3 | 小头欠拟合，大头过拟合 |
| 解冻 | Top-8 | Top-6 欠适配，Top-10/全解冻稳定性较差 |
| Consistency | 0 | 非零权重主要改变置信度，不改善排序 |

## 6. 影响下游性能的主要因素

### 6.1 数据与评估定义

受试者隔离、无效试次筛选、area 归一化和任务完整性首先决定结果是否可信。旧 area-stat 偶尔获得异常高收益，说明面积可能同时携带生理信息、设备尺度和受试者身份。严格四任务降低缺失模式偏差，但会减少样本；PD5 少数类人数很少，使单个受试者即可明显改变结果。

### 6.2 预训练任务与疾病时间尺度

MCI 更依赖抑制、记忆和跨时段任务规则，因此偏好较强、较长的连续遮挡。PD5 更依赖局部眼跳动力学，过长遮挡会移除有价值的短时运动。两任务对 span 的偏好冲突，是统一 BERT 的主要限制。

### 6.3 Tokenizer 质量

Tokenizer 需要同时保持连续信号可重建、离散码充分使用和辅助特征不过拟合。当前码本已经接近全使用，FSQ 容量不是主要瓶颈。Area 仍比 XY 难重建，但 Area loss 的下降不能直接等价为疾病性能提升。

### 6.4 受试者证据量与微调容量

K16 通过观察更多试次降低受试者预测的抽样方差。继续增加 K 会排除试次不足的受试者，可能抵消收益。下游样本规模远小于预训练数据，因此过大的分类头、任务专用 head、动态 task weight 和过多解冻层通常增加验证波动。

### 6.5 预训练指标与下游指标不等价

BERT loss 衡量被遮挡 code 是否容易预测；下游 AUROC 衡量疾病受试者的排序。容易预测的局部动态未必包含疾病信息，因此更低的预训练 loss 或更长训练不保证更高下游 AUROC。PD5 的 macro-AUROC 与 balanced accuracy 不一致，则提示其剩余问题更多来自类别决策和校准，而不是完全缺乏排序信息。

## 7. 最终方案与结论

已完成消融所选出的历史统一参考采用 V4 数据。当前 V5 因构建时重复滤波而不纳入正式比较，需以“交付坐标零修改”的方式重新生成后再复验。模型侧建议暂不因这批无效 V5 结果改变。

该方案不是每个单任务的最高点，而是 MCI 与 PD5 之间最稳定的验证集折中。若只优化 MCI，可优先选择长度1–6对称遮挡；若优先提高 PD5，应首先处理少数类规模和决策校准，而不是继续扩大 span、FSQ 或模型容量。

当前最需要完成的是最新 stimulus-to-CLS 隔离模型的三种子下游验证。之后应固定架构，在独立外部队列上验证泛化。
